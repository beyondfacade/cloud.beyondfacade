# 외부 참고 후보 (2026-09-23)

두 사이트를 훑고 우리 프로젝트(서울 상권 아틀라스)에 적용할 만한 것만 남겼다.
코드·스타일을 그대로 가져올 항목은 없다. 아이디어와 표현 방식만 참고한다.

| 출처 | 성격 | 참고 범위 |
|---|---|---|
| 모닝컵 — https://1-production-fc29.up.railway.app/static/index.html | 매장 수요 예측 데모 (바닐라 JS + Python/Prophet, 서울시 실시간 도시데이터 + OpenWeatherMap) | 데이터 신뢰성 표기 방식 |
| 오픈인서울 — https://openinseoul.foodtrend.news | 카페 창업 경영 시뮬레이션 게임 (하드코딩 가상 데이터, 실데이터 호출 없음) | 상권을 한 줄로 압축하는 카피 구조 |

---

## 1. 값마다 출처 배지를 붙인다 — 모닝컵

모닝컵은 카드·패널마다 출처를 한 단어로 표시한다.

```
시연용 가상 데이터 / 서울시 실시간 데이터 / OpenWeatherMap 예보 / 미연결
```

**우리 적용처**
- 지도 사이드패널 현황(어린이집·편의점·스냅샷 점포수)과 지표 카드에 `출처 · 기준일` 배지.
- 데이터는 백엔드 스냅샷에 이미 있으므로 표시만 추가하면 된다.

**우선순위:** 1

---

## 2. 오해 방지 문구를 값 바로 옆에 둔다 — 모닝컵

푸터나 별도 페이지가 아니라 카드 디테일 줄에 넣는다.

> 주변 인구는 실제 매장 방문객 수와 다릅니다.
> 성별·연령대 비율은 별도 항목입니다. 두 비율을 곱해 특정 성별·연령의 실제 인구수로 간주하지 않습니다.
> 모델의 80% 설정 구간이며 실제 포함률을 보장하지 않습니다.

**우리 적용처**
- 유동인구·점포수 지표의 해석 주의 문구를 범례 하단 또는 리포트 verdict 섹션에 고정.
- AI 리포트가 수치를 낼 때 같은 톤의 한계 고지.

**우선순위:** 4

---

## 3. 상권 프로필을 고정 슬롯으로 정의한다 — 오픈인서울

게임의 상권 5곳(강남·을지로·성수·신촌·강동)이 같은 구조로 정의되어 있다.

| 슬롯 | 예시 (강남 테헤란로) |
|---|---|
| tagline (한 줄) | 유동은 최강, 임대료도 최강 |
| description (3문장) | 오피스 밀집의 왕. 아침·점심 후 테이크아웃 커피가 폭발하지만 … 주말이면 거리가 비워진다. |
| mix (고객 구성) | office_worker 62 · mz_hotple 12 · delivery 12 · resident 8 · studier 6 |
| phases (시간대 특성) | 출근길 테이크아웃 러시 → 회의 커피 시간 → 다들 식사 중 — 한산 → 식후 아메리카노 러시 → 퇴근 후 공동화 |
| warning (한 줄 경고) | 제조가 3분만 밀려도 직장인은 옆 프랜차이즈로 갑니다. 주말 매출은 기대하지 마세요. |
| research (시세 3항목) | 부동산 시세 / 동종업계 매출 / 인근 시급 시세 |

**우리 적용처**
- AI 리포트 `market` 섹션이 현재 자유 마크다운이다. 한 줄 요약·주의점·시간대 특성·고객 구성을 프롬프트 출력 계약으로 고정하고, `report-view.tsx`에서 슬롯별로 렌더링하면 리포트 품질이 일정해진다.
- 숫자 자체는 가상 데이터이므로 근거로 쓰지 않는다. 구조만 참고한다.

**우선순위:** 2

---

## 4. 시간대 지표를 사람 말로 번역한다 — 오픈인서울

시간대별 유동 값에 서사 라벨을 붙인다.

```
출근길 테이크아웃 러시 · 다들 식사 중 — 한산 · 카공 피크 · 힙지로의 밤 · 퇴근 후 공동화 · 텅 빈 오피스 거리
```

**우리 적용처**
- 지도 브리핑 패널이나 리포트에 시간대 유동인구가 들어갈 때, 숫자 옆에 이런 어휘를 붙인다.
- 항목 3의 phases 슬롯과 함께 프롬프트 계약에 넣을 수 있다.

**우선순위:** 3 (항목 3에 묶어서 진행)

---

## 5. 랜딩 카피에 구체 효용 한 줄 — 오픈인서울

게임 랜딩은 비용 대비 가치를 숫자로 말한다.

> 수천만 원을 쓰기 전에, 먼저 15분만 투자해서 카페 한 번 운영해보세요.
> 매출보다 중요한 '사장 시급'까지 계산합니다.

**우리 적용처**
- 현재 랜딩 히어로("서울의 변화 속에서, 내 가게의 자리를 찾다")는 감성 카피만 있다.
- 히어로 아래 한 줄을 구체 효용으로 보강한다. 예: "행정동 425개 × 업종별 지표를 3분 안에."

**우선순위:** 3

---

## 6. 모바일 제약 안내 배너 — 오픈인서울

키보드 필수 기능을 첫 화면에서 한 번만 알리고 `sessionStorage`로 닫힘 상태를 기억한다.

**우리 적용처**
- 지도가 좁은 화면에서 제약이 있을 때 같은 패턴을 쓴다. 가볍고 의존성이 없다.

**우선순위:** 5 (필요해질 때)

## 참고하지 않는 것

- 모닝컵 UI: 사이드바 + 카드 3열 템플릿, 하드코딩 hex, CSS 중복. 스타일 참고 가치 없음.
- 모닝컵 Prophet 매장 시계열 예측: 우리 범위(행정동 단위 탐색·분석)와 다름.
- 오픈인서울 수치 전부: "공공자료의 구조를 참고해 재구성한 가상 데이터"라고 자체 고지. 근거 자료로 쓰면 안 됨.
- 오픈인서울 픽셀 폰트(neodgm, galmuri)와 게임 톤: 아이보리·청록 아틀라스 톤과 맞지 않음.
