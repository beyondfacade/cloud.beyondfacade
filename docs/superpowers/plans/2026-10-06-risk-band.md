**Goal:** 판정 신호 근거의 "서울 상위/하위 N%"를 판정 임계값과 같은 경계의 5단계 위험 등급 낱말로 바꾸고, 숫자는 "서울 ○○ 동을 100곳으로 치면 ○○ 쪽에서 N번째쯤" 설명과 함께 남긴다. 지도 카드·리포트·직접 답이 같은 문장을 쓴다.

**Architecture:** verdict BC 도메인에 순수 모듈 `risk_band.py`(백분위 → 등급 코드)를 두고, 신호마다 재는 것·나쁜 쪽·좋은 쪽 낱말을 클래스 속성으로 갖는다(Strategy). `Signal.evaluate`가 사실 문장(`evidence`) 뒤에 등급 구를 붙이고 `SignalResult`에 `band`·`band_label`을 싣는다. 근거는 DB `signals_json`에 저장되므로 배치(`build_verdicts`) 재실행으로 반영된다.

- 등급 경계: 위험 백분위 p ≥ `strong_percentile`(90) → `very_bad`, p ≥ `on_percentile`(75) → `bad`, p ≥ 25 → `normal`, p ≥ 10 → `good`, 그 밖 → `very_good`. 75·90은 `VerdictThresholds` 값을 그대로 쓴다(하드코딩 금지).

`risk_band.py`:
```python
"""위험 백분위 → 5단계 등급 (stdlib·도메인만). 경고·강한 경고 경계는 판정 임계값(75·90)을 그대로 쓰고,
좋은 쪽 두 경계(25·10)는 그 대칭이다 — 근거 문장의 등급 낱말이 판정과 어긋나지 않게 한다."""

from apps.verdict.domain.services.thresholds import VerdictThresholds

BANDS = ("very_bad", "bad", "normal", "good", "very_good")
_GOOD_PERCENTILE = 25.0  # on_percentile(75)의 대칭
_VERY_GOOD_PERCENTILE = 10.0  # strong_percentile(90)의 대칭


def band_of(percentile: float, thresholds: VerdictThresholds) -> str:
    """위험 백분위 → 등급 코드. 순서 비교라 조건 표를 위에서부터 훑는다."""
    for floor, band in (
        (thresholds.strong_percentile, "very_bad"),
        (thresholds.on_percentile, "bad"),
        (_GOOD_PERCENTILE, "normal"),
        (_VERY_GOOD_PERCENTILE, "good"),
    ):
        if percentile >= floor:
            return band
    return "very_good"
```

`signals.py`:
- `Signal`에 클래스 속성 `measure: str`, `bad_word: str`, `good_word: str`과, 등급 낱말 표:
```python
_BAND_WORDS = {
    "very_bad": lambda s: f"매우 {s.bad_word} 편",
    "bad": lambda s: f"{s.bad_word} 편",
    "normal": lambda s: "보통",
    "good": lambda s: f"{s.good_word} 편",
    "very_good": lambda s: f"매우 {s.good_word} 편",
}
```
- `Signal.band_label(band) -> str`: `f"{self.measure} {_BAND_WORDS[band](self)}"`.
- `Signal.evaluate`: 백분위를 낸 뒤 `band = band_of(percentile, t)`; evidence는 `f"{self.evidence(i, value)} — {self.band_label(band)}(서울 {i.industry_name} 동을 100곳으로 치면 {self.bad_word} 쪽에서 {_top(percentile)}번째쯤)"`; `SignalResult(..., band=band, band_label=self.band_label(band))`.
- 각 신호의 `evidence(i, value, percentile)` → `evidence(i, value)`로 바꾸고, 문장에서 **"서울 ○○ 상위/하위 N%" 부분만** 뺀다(남은 괄호 내용은 유지, 빈 괄호는 지운다). 예: 순유출 `"지난 12개월 폐업 5곳, 개업 5곳 (순유출률 +0%)"`, 생존 `"3년 전 개업한 한식 20곳 중 11곳만 남음 (생존율 54%)"`, 조기 폐업 `"최근 3년 폐업 한식의 영업 기간 중위 36개월"`, 포화 `"상주인구 1,000명당 당구장 0.6곳"`, 폐업률 `"지난 4분기 폐업 12곳 (4분기 전 점포 120곳의 10%, 서울시 상권분석 집계)"`, 담배권 `"이 동 상가 자리 200곳 중 60%가 영업 중인 담배소매인 50m 안 — 새 담배소매인 지정이 어렵다"`, 사무소당 거래 `"… = 사무소당 3.2건 (국토부 실거래가)"`.
- `ShrinkingSignal`(이진)은 등급 없음 — `evaluate` 재정의 그대로, evidence 시그니처만 맞춘다. `SourcedSignal`·`UnsupportedSignal`은 위임·고정 문장 그대로(속성은 inner에서 가져오거나 Null Object라 불필요 — `SourcedSignal.evaluate`가 inner.evaluate를 부르므로 추가 작업 없음).
- `SignalResult`(entity): `band: str | None = None`, `band_label: str | None = None` 끝에 추가. ORM 매퍼 `SignalResult(**item)`은 옛 행(필드 없음)도 기본값으로 읽는다 — 그대로 둔다.
- DTO·스키마·인바운드 매퍼에 두 필드를 통과시킨다(같은 이름, nullable).
