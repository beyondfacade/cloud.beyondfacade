# 서울 상권 아틀라스 랜딩

사용자가 2026-09-17 승인한 범위: 랜딩에만 Blender 렌더 이미지와 가벼운 CSS 모션을 적용한다. 기존 지도와 AI 분석 기능은 유지한다.

- `/`: 큰 한국어 제목, 상권 탐색 CTA, 서울 미니어처와 위치 핀, 기능 라벨 3개. 이어서 서비스 소개와 이용 순서를 짧게 안내한다.
- `/map`: 기존 지도 페이지를 그대로 조립한다. 이전 `/?region=…&industry=…` 같은 지도 쿼리 링크는 쿼리를 보존해 `/map`으로 연결한다.
- 비주얼: 밝은 아이보리, 무광 세라믹 건물, 청록색 한강·상점. 서울을 표현한 개념 모형이며 실제 점포 위치나 통계로 오인시키지 않는다.
- 자산 계약: `/landing/seoul-diorama.webp` (1600×1400, 투명 배경), `/landing/location-pin.webp` (256×320, 투명 배경). Blender 원본 생성 스크립트와 `.blend` 파일도 제공한다.
- 실시간 3D·새 JS 라이브러리는 추가하지 않는다. 랜딩에서 지도 모듈과 지도 API를 로드하지 않는다. 지도 링크의 자동 prefetch도 끈다.
- 모션: 모형의 첫 등장, 위치 핀의 작은 상하 이동, 라벨의 순차 등장. 모바일 및 reduced-motion에서는 정지한다. 텍스트와 CTA는 이미지와 독립된 HTML이다.
- 공통 의미 토큰은 세 화면의 아이보리/청록색 톤을 공유하고, 랜딩 장식 효과는 전용 토큰과 CSS 범위로 관리한다. 지도·분석 스타일도 아래 승인된 확장 범위에 맞춰 조정한다.
- 반응형, 키보드 focus, 명도 대비, 이미지 실패 시에도 작동하는 탐색 CTA를 검증한다. 원본 수정 중이던 사용자 문서는 변경하지 않는다.

완료 기준: Blender 자산 실제 렌더, 랜딩과 CTA/기존 링크 동작, 데스크톱·모바일·다크·reduced-motion 확인, 전체 단위 테스트 및 프로덕션 빌드 통과.

## 승인된 범위 확장 — 지도·AI 화면 톤 통일

사용자가 구현 도중 지도 탐색과 AI 분석도 랜딩과 같은 톤으로 수정하고, 서브에이전트 방식으로 진행하도록 요청했다.
기존 지도 화면의 스타일 유지 제한은 이 요청으로 대체되며, 지도 동작·API·색상 스케일과 AI 분석 상태·데이터 계약은 유지한다.

- 공통 UI 토큰과 헤더를 랜딩의 따뜻한 중립색/청록색으로 통일한다. 기존 지도 데이터 팔레트는 별도 체계를 유지한다.
- 지도: 제목·필터 트레이·지도 프레임·지역 브리핑 패널의 위계를 정리한다. 좁은 화면에서는 지도와 패널을 세로로 배치한다.
- AI: 제목, 입력/진행 패널, 리포트 빈 상태와 문서 위계를 같은 톤으로 다듬는다. 기존 입력·분석 실행·SSE·인용 기능은 보존한다.
- 추가 3D 자산이나 새 라이브러리, 새 데이터 호출은 넣지 않는다.
- 지도 에이전트, AI 에이전트, 공통 UI/통합 검증 담당으로 편집 소유권을 분리한다.
