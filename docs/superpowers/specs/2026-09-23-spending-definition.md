# 서울시 상권분석서비스 소비(지출) 데이터 정의 확인 — 유입·유출 지수 성립 여부

- 작성일: 2026-09-23
- 대상 데이터: `data/raw/seoul_commerce/spending_adstrd/` (OA-22166, 소비-행정동), `data/raw/seoul_commerce/sales_adstrd/` (OA-22175, 추정매출-행정동)
- 성격: 조사·판정 문서. 코드·데이터 변경 없음.

## 판정 (결론)

**발생지 기준 확실.** `지출_총금액`은 "그 동에 사는 사람이 쓴 돈"이 아니라 **그 동에 소재한 KB카드 가맹점에서 결제된 금액**이다. 서울시 상권분석서비스 공식 데이터 출처표가 소비 항목의 원천을 `KB카드 / 가맹점 매출(소비트렌드)`로 명시하고, 10개 세부 항목은 `KB카드 소비트렌드 비율(교육, 교통, 기타상품 및 서비스, 생활용품, 식료품, 여가문화, 유흥, 음식, 의료, 의류신발)`을 곱해 분해한 값이다 — 우리 CSV의 10개 컬럼과 정확히 일치한다. 데이터 증거도 같은 방향이다. 1인당 분기 지출 중앙값이 **21.5만원**(가계 실제 소비지출은 분기당 1인 350~400만원 수준)으로 가계 소비 추계와 자릿수가 다르고, `log(지출)`은 상주인구(r=0.135)보다 직장인구(r=0.658)·추정매출(r=0.757)과 훨씬 강하게 붙으며, 상위 5개 동(소공동·구로3동·문래동·역삼1동·역삼2동)이 서울 전체 지출의 **61.0%**를 차지한다 — 온라인·본사 소재 대형 가맹점이 등록 주소로 매출을 몰아 잡는 전형적 발생지 데이터 형태다. **따라서 "지출 대 매출" 유입·유출 지수는 폐기한다.** 두 숫자는 서로 다른 카드사(KB 대 신한)가 같은 동의 가맹점 결제를 각자 집계한 것이므로, 비교해서 나오는 값은 유입·유출이 아니라 카드사 점유율 차이와 업종 커버리지 차이다. 다만 **지출 10항목 구성비는 "그 동 가맹점에서 돈이 어느 항목으로 흘러가는가"로 재해석하면 사용 가능**하며, 창업 업종 선택 지표로는 오히려 이쪽이 직접적이다. 단 상위 20개 동과 단일 항목이 50%를 넘는 72개 동은 본사·단일 가맹점 오염으로 제외해야 한다.

**거주지 기준이었다면 나와야 했던 패턴** — 오피스가는 지출 << 매출, 주거지는 지출 >> 매출 — 이 **전혀 나타나지 않는다.** 오히려 정반대다. `지출/매출`이 1을 넘는 15개 동은 전부 오피스·본사 밀집지(소공동 14.3, 구로3동 12.2, 문래동 11.7, 용산2가동 9.4, 역삼2동 7.2)이고, 주거지 동들은 0.1~0.4 구간에 몰려 있다. 주민 소비가 잡히는 데이터라면 절대 나올 수 없는 배치다.

## C. 유입·유출 지수 — 폐기

**쓰지 않는다.** 근거:

1. **두 숫자가 같은 쪽 현상을 잰다.** 지출(KB카드 가맹점 매출)과 추정매출(신한카드 결제금액 ÷ 보정비율)은 둘 다 발생지 기준이다. 나누면 "그 동에서 발생한 결제" ÷ "그 동에서 발생한 결제"이며, 남는 것은 카드사 점유율 차이·업종 커버리지 차이·보정 여부 차이뿐이다.
2. **비율이 실제로 그렇게 움직인다.** 서울 전체 지출/매출이 20분기 내내 0.41~0.51 좁은 대역에 갇혀 있고, 동별 중앙값 0.141은 카드사 점유율 대역이다. 유입·유출의 신호가 아니라 집계 방식 차이의 상수다.
3. **극단값이 전부 본사 오염이다.** 비율 상위 10개 동(소공동 14.3 ~ 회현동 1.8)은 "돈이 몰려 들어오는 동"이 아니라 "대형 가맹점 본사가 등록된 동"이다. 이 지수를 그대로 노출하면 사용자에게 소공동·구로3동·문래동을 서울 최고 소비 유입 상권이라고 말하게 된다 — 명백한 오독이다.
4. **주민 소비 쪽 숫자가 아예 없다.** 유입·유출을 말하려면 거주지 기준 소비가 필요한데, 상권분석서비스 계열 어디에도 없다. 소득분위(국민건강보험공단, 주거지 기반)가 유일한 거주지 기준 지표였으나 그마저 `월_평균_소득_금액`은 2026-05-13 삭제, `소득_구간_코드`는 2026-06-25 삭제 예정이다.

**대안이 필요하다면** 거주지 기준 소비를 따로 확보해야 한다. 후보:
- 통계청 가계동향조사 (전국·시도 단위, 행정동 없음 — 해상도 부족)
- 신한카드·BC카드의 거주지 기준 소비 데이터 (상권분석서비스에는 포함되지 않음, 별도 수급 필요)
- 서울시에 직접 문의 (데이터분석팀 02-2174-5075) — 다만 이번 판정을 뒤집을 만한 여지는 문서상 없다고 본다. "가맹점 매출"이라는 문구가 명시적이다.

**이 데이터로 대신 말할 수 있는 것:** "이 동에서 결제되는 돈의 규모와 성격". 유입·유출이 아니라 상권 규모·업종 구성 축이다.

## D. 지출 항목 구성비 — 조건부 사용 가능

### D-1. 성립 여부

**성립한다. 단, 문장을 바꿔야 한다.**

- ❌ "이 동 주민은 교육비를 많이 쓴다" — 성립하지 않는다. 발생지 데이터이므로 주민 소비 바구니가 아니다.
- ✅ "이 동에서 결제되는 돈의 N%가 교육 관련 가맹점으로 간다" — 성립한다.

그리고 **학원과 술집 중 무엇을 열지 고민하는 사람에게는 후자가 오히려 직접적이다.** 그 사람이 알고 싶은 것은 "이 동 주민이 어디서든 쓰는 교육비"가 아니라 "이 동 안에서 학원업이 실제로 얼마나 돈을 만드는가"다. 발생지 기준이 바로 그 질문의 답이다.

신뢰도 근거: 항목 합이 총액의 100%를 정확히 덮고(B-1), 동별 항목 비중은 분기 간 안정적이다(최근 4분기 교육 비중 표준편차 중앙값 0.29%p, p90 0.98%p).

### D-2. 반드시 걸러야 할 오염

본사·단일 대형 가맹점이 동 전체를 삼킨 경우 구성비는 무의미하다.

| 진단 지표 (2025Q4, 425동) | 분포 |
|---|---|
| 최대 항목 비중 중앙값 | 0.355 |
| 최대 항목 비중 p75 / p90 / p95 / p99 | 0.448 / 0.586 / 0.750 / 0.958 |
| 최대 항목 비중 > 0.5 인 동 | **72개** |
| 최대 항목 비중 > 0.7 인 동 | **24개** |
| 1인당 분기 지출 p90 / p95 | 137.6만원 / 372.1만원 |

**권장 2단 필터 (둘 중 하나라도 걸리면 구성비 비노출 또는 경고 표시):**

1. **단일 항목 비중 ≥ 50%** — 72개 동 제외. 본사·플랫폼 가맹점 오염의 직접 신호.
2. **1인당 분기 지출 ≥ 150만원** (≈ p90) — 소공동·회현동·구로3동·문래동·을지로동·명동·역삼1·2동·종로1·2·3·4가동·용산2가동 등 제외. 가계 소비 상한을 벗어난 동.

두 필터를 통과한 동만 항목 구성비를 노출한다. 참고로 지출 총액 상위 20개 동(서울 전체의 78.5%)은 대부분 이 필터에 걸린다.

경계 사례: 보라매동(교육 74.2%, 교육 지출 100억원, 상주 23,092명 → 1인당 분기 교육비 43만원)은 실제 대형 학원 밀집인지 단일 교육기업 본사인지 이 데이터만으로 구분할 수 없다. **필터 1에 걸려 제외되는 쪽이 안전하다.**
